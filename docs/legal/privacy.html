EDICT — Privacy Policy

Last updated: 2026-05-25 · Applies to all installations of the EDICT Devvit app.

1. What we store

  • Rule sources and compiled JSON. The English rule text a moderator typed, the compiled clause tree, and the rule’s full lifecycle (drafted, compiled, activated, promoted, paused, archived).
  • Audit entries for evaluations. When a rule evaluates against a post or comment, EDICT records: the rule ID, the matched clause name, the captured fact-bag values (e.g. postBodyLength, authorKarmaTotal), the resulting verdict, and a rollback token. EDICT does not store post or comment bodies verbatim — only the derived fact-bag slots the rule actually read.
  • Reversal fingerprints. When a moderator reverses an action, EDICT stores a DJB2 hash of the fact-pattern that fired, so future similar patterns are deprioritized. The hash cannot be reversed back into the original post text.

2. Where it’s stored

All data lives in Devvit’s hosted Redis, scoped per app installation. Each subreddit’s data is isolated by Devvit’s multi-tenancy boundary — no install can read another’s data. EDICT does not run a separate backend service.

3. What we send to third parties

  • OpenAI — at rule-edit time only. The plain-English sentence a moderator wrote, EDICT’s structured-output schema, and a handful of compiler exemplars are sent to api.openai.com. No post body, comment body, or user identifier is ever sent. OpenAI’s data-handling terms apply to that payload.

EDICT does not contact any other third party. The full http.permissions.domains allowlist in devvit.json is one entry: api.openai.com.

4. Retention

Audit entries persist for the configured rollbackWindowDays (default 30) plus a 90-day analytics tail, then a nightly compaction job trims them. Rule definitions persist until a moderator archives the rule. Reversal-fingerprint hashes have no automatic expiry but can be cleared with npm run replay -- --reset-learning.

5. Your data rights as a subreddit member

If you posted or commented in a subreddit running EDICT and want to know whether a moderator action was taken by EDICT, an EDICT audit entry for your post is accessible to the subreddit’s moderators via the Command Center’s Explain this decision menu item. Contact the subreddit’s mod team if you need an explanation; mods can also use the rollback workflow to undo an EDICT action within the rollback window.

6. Children

EDICT is not directed at children under 13. Use of EDICT is bound by Reddit’s underlying age requirements for the platform.

7. Changes

We will update this page when the data EDICT handles, the third parties it talks to, or the retention windows change. The “Last updated” date at the top of this page reflects the most recent change.
